# MythicWorldLib

## 📖 Introduction
MythicWorldLib is a **shared library** for my MythicWorld mods.  
It provides a reusable **network stack framework** and several utilities that support my mods.

---

## ⚙️ Functions
- **Custom network stack**  
  Handles network transport with Payloads in Login and Play phase.
- **Utilities**  
  Minecraft environment detector and reflections.

---

## 🚀 Usage
- Runs on **Minecraft 1.21.1 Fabric**.
- Designed to be used alongside mods such as **MythicWorldTweaks** and others in the MythicWorld suite.
